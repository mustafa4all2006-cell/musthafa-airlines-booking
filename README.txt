MUSTHAFA HUSSAIN AIRLINE - MULTI PAGE WEBSITE

Files:
1. index.html       -> Home page
2. flights.html     -> Flight schedule and search
3. booking.html     -> Flight booking + ticket generation
4. about.html       -> About page
5. contact.html     -> Contact form
6. style.css        -> Common website styling
7. script.js        -> Common JavaScript functionality

HOW TO RUN:
1. Extract the ZIP file.
2. Open index.html in Google Chrome, Edge, or Firefox.
3. Use the navigation menu to move between pages.

IMAGE:
The website currently uses Unsplash image URLs.
To use your own image:
- Create an "images" folder.
- Put your image inside it.
- Replace the Unsplash URL in index.html/about.html or the CSS hero background
  with something such as images/airplane.jpg.

NOTE:
This is a B.Tech student project. Flight schedules, prices, PNR and booking
confirmation are sample/demo data. It is not connected to a real airline,
payment gateway, airline API, or production database.
